# Cuestionarios de ansiedad y depresión — Consultorio Médico Salvatierra

Sitio estático con dos modalidades independientes:

- **Evaluación médica:** `medico/` — HAM-A (14 ítems) y HAM-D (17 ítems) como apoyo a entrevista clínica.
- **Autorreporte:** `paciente/` — cuestionarios de síntomas que el paciente completa sin asistencia; no son escalas Hamilton autoadministradas validadas.

## Publicación con GitHub Pages

Subir **el contenido de este ZIP** a la raíz de la rama `main` del repositorio `chuby007/hamilton-pacientes`. En **Settings → Pages**, seleccionar **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar. La URL será `https://chuby007.github.io/hamilton-pacientes/`.

## Privacidad

Las respuestas se procesan en el navegador, sin servidor ni base de datos. No incluir información identificable del paciente en el repositorio público.

Página del consultorio: https://consultoriosalvatierra.com/
